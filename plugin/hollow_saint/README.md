hollow_saint: Cathedral of the Hollow Saint, a haunted hurdy-gurdy (kennel synth plugin for the original OP-1).

Blue DRONE (push: FOLLOW / fixed key C..B), green STRINGS, white WHEEL BUZZ (push: stroke rate steady / 1/4 / 1/8 /
1/8T / 1/16 of the tempo), red CATHEDRAL. Presets in presets/ (python3 presets.py rebuilds them). The screen is generated
by tools/gen_screen.py in the project repository. Pack: python3 tools/kennel/pack.py synth_sdk/plugins/hollow_saint -o
build/hollow_saint.knl. GPL-3.0-or-later with the OP-1 firmware permission.
