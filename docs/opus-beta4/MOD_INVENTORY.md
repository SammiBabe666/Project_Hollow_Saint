## Hollow Saint (`SammiBabe666/Project_Hollow_Saint`)

- **Source:** `plugin/hollow_saint/hollow_saint.c` is the one engine (kennel API). `opus/sammi.hollow_saint/` is the
  Opus glue: `hollow_saint_opus.c` `#include`s the kennel engine unchanged, and `op1_plugin.h` supplies the kennel API
  on Opus. `hs_sine.h` and `hs_svg.h` are generated by `tools/gen_opus_headers.py`. This is already the
  architecture/DSP split the brief asks for.
- **Engine:** haunted hurdy-gurdy. Six OS voices (`OPUS_ENGINE_OS_VOICES`), drone + melody strings + wheel buzz into a
  CATHEDRAL reverb; Lo-Fi Relic (a worn tape stage); drone key FOLLOW or C-B; stroke rate locked to the metronome.
- **Controls:** blue DRONE (push: drone key page), green STRINGS (push: relic on/off, then age), white WHEEL BUZZ
  (push: stroke rate page), orange CATHEDRAL. Page words 5-7 saved with `opus_engine_knob_set`.
- **Presets:** eight `.aif` sounds (`type: hollow saint`), generated by `presets.py`.
- **Screen:** its own SVG (`hollow_saint.svg`, written to the plugin folder, driven by `fw_svg_node_find` /
  `fw_node_set_matrix` / `fw_screen_draw`); four-bar fallback page if the file can't be written.
- **External dependencies:** kit headers; firmware #246 raw reads: velocity `0xFF801064`, beat clock `0x01AADABC`,
  tape speed/position `0xFF802970/74`, voice objects `0xFFB00000 + 0x24 i`.
- **Build:** `tools/build_opmod.sh` (needs `OPUS_KIT` and the shared toolchain). Kennel `.knl` via `tools/build_knl.sh`.
- **Known bugs / limits:** CPU clicks being fixed separately (PR #7, not touched here); CPU figure is an estimate; the
  repo carries a kennel-era `toolchain/build_toolchain.sh` (binutils 2.42) against the shared-toolchain rule.
- **Beta 4 risks:** the raw reads above (highest); the `type` bridge for kennel sounds; the OS-voice layout.

## Bloodmoon (`SammiBabe666/Project_Bloodmoon`)

- **Source:** reference engine in `platforms/op1/src/plugins/bloodmoon/` (op1r); Opus port in
  `platforms/opus/src/noladrift.bloodmoon/` (`bloodmoon.c`, `moon.c`, `bm.h`, generated `bm_art.h` / `bm_sine.h`),
  held to the reference by `platforms/opus/tests/compare.c`.
- **Engine:** dark organ + haunted bell: fundamental with 2nd-4th harmonics plus two inharmonic bell partials
  (1.1875x, 2.40625x), Q15 integer maths, vibrato and pitch instability LFOs.
- **Controls:** the OS's four knobs only: BLOOD, ECLIPSE, HAUNTING, MOONRISE. No `uses` lines.
- **Presets:** eight Opus `sound.json` presets (`platforms/opus/presets/`), not yet confirmed to load; op1r/kennel
  `.aif` set separately. The docs note Opus's author says bridged-type sounds may not load.
- **Screen:** v1.3's moon and cathedral SVG through the `fw_*` node calls; `moon.c` declares `fw_screen_draw` with a
  `dt` argument itself instead of using op1fw.h's one-argument form (documented in the file).
- **External dependencies:** `fw_node_set_matrix`, `fw_screen_draw`, `fw_snprintf`, `fw_svg_node_find`;
  `opus_fast` (~4.2 KB). No raw addresses.
- **Build:** `tools/build-platform/build-opus.sh` (`OPUS_KIT`, `OP1_BFIN_TOOLCHAIN`). CI
  (`.github/workflows/build-opus.yml`) builds the toolchain on GitHub runners: against the shared-toolchain rule.
- **Known bugs / limits:** 1.5.0/1.5.1 switched off on the OP-1 for CPU; 1.5.2 brought the simulator figure from
  247,335 to 68,207 cycles but is untried. **1.5.3 exists only on the Mac** (`archive/bloodmoon-1.5.3-build-src.tgz`,
  a test `.opmod`): not in the repo.
- **Beta 4 risks:** the hand-declared `fw_screen_draw` signature; the type bridge for presets; CPU figure.

## Erdtree (`SammiBabe666/Project_Erdtree`)

- **Source:** Hundekraft/op1r v0.5 in `platforms/hundekraft/src/`; Opus 0.6.1 in `platforms/opus/src/sammi.erdtree/`
  (`erdtree.c` the voices, `erd_page.c` the T1 tree, generated `erd_tables.h` / `erd_art.h`).
- **Engine:** an orchestra per voice: choir (formant wave), strings, brass (timbre follows the envelope), and SPACE
  for distance.
- **Controls:** blue choir, green strings, white space, orange brass; a `screen` setting (animated / still).
- **Presets:** eight Opus `sound.json` presets (crown-of-ash ... vesperglass) plus the Hundekraft set.
- **Screen:** the Erdtree over Leyndell drawn with `opus_page_*` and `opus_page_still`, ~10 fps, an art layer in
  `opus_alloc` memory.
- **External dependencies:** core 2.8 (`opus_alloc_audio`, `opus_page_still`); `opus_fast` for the voice tables; raw
  read of the OS's envelope gains `0xFF801D50` inside render; inline asm (`CYCLES`, a 16x16 multiply).
- **Build:** `scripts/build-platform/build-opus.sh KIT TC`. The shipped 0.6.1 `.opmod` differs from today's rebuild
  (same size and imports, 4,247 bytes different): it wasn't built with this toolchain.
- **Known bugs / limits:** 0.6.0 silent on an OP-1 (most likely the CPU guard); 0.6.1 is the fix, untried.
- **Beta 4 risks:** the `0xFF801D50` read (the brass timbre depends on it); CPU figure.

## Sister / Dark Sister (`SammiBabe666/-Sister-Opus-OP-1-Port`)

- **Source:** Hundekraft's SISTER (Workshop 3.1.1) kept untouched in `upstream/sister/`; the Opus plugin in
  `plugin/sammi.sister/`: SISTER's DSP unchanged (`sister_dsp.c`, `sister_kern.c`, `sister_asm.S`,
  `sister_tables.h`) plus the port's glue (`sister_opus.c`) and page (`sister_page.c`).
- **Effect:** stereo cathedral reverb whose tail sings (CHOIR), rings in tune (PIPES) or swells backwards (VESPER);
  the port adds DARK (shift + orange; 0 = byte-identical SISTER).
- **Controls:** blue SPACE, green VOICE, white SWELL, orange MIX; shift + green pipes key; green push semitones/cents.
- **Presets:** none of its own (effect settings live in the user's sounds).
- **Screen:** SISTER's nave/rose/nun/candles page on Opus drawing calls, drawn under the OS screen.
- **External dependencies:** `fw_shift_held`; Blackfin assembly kernels. No raw addresses.
- **Build:** `build.sh` (shared toolchain via `env.sh`). Rebuild is byte-identical to `dist/darksister.opmod`.
- **Known bugs / limits:** CPU is Hundekraft's unit model plus margin; "assumption, not verified on hardware: the OS
  stops calling a switched-off effect's process".
- **Beta 4 risks:** low; the effect service (module model v2) and drawing calls.

- **Source:** `reverb.c` (the port), original kept at `third_party/hundekraft-3.1.1-reverb.c.orig`; diff in

- **External dependencies:** `fw_snprintf` only.
- **Build:** `tools/build.sh`; rebuild byte-identical to `release/sammi.reverb.opmod`.
- **Known bugs / limits:** no `cpu.txt`, so it is held to 58,052 cycles; simulator figures only.

## Hundekraft Studder (same repo, `plugins/sammi.stutter`)

- **Source:** `stutter.c`, original at `third_party/hundekraft-3.1.1-stutter.c.orig`.
- **Effect:** beat-locked stutter with repeat, brake, reverse and gate; bit-identical to Hundekraft's.
- **Controls:** blue rate, green mode, white shape, orange chance; shift + blue repeats (2-16), shift + orange freeze.
- **Screen:** "the defective tape head", under the OS screen.
- **External dependencies:** `fw_snprintf`; raw reads of the beat clock `0x01AADABC` and tape speed/position
  `0xFF802970/74` (once per block). The build's `deep` line says "none": the loader doesn't know about them.
- **Build:** as Reverb; rebuild byte-identical to the release.
- **Known bugs / limits:** no `cpu.txt`; the beat lock depends entirely on the raw reads.
- **Beta 4 risks:** **high** for the beat clock; the effect's whole point rests on it.

## Future engines and effects

Start from the pattern Hollow Saint, Sister and ROOMS already use: DSP in files with no Opus names in them, a thin
glue file that is the only one including `opus_plugin.h`, a host test that runs the DSP alone, and a `cpu.txt`
measured on the device before sharing. Avoid raw firmware addresses; if one is unavoidable, wrap it as in
RECOMMENDATIONS.md.
